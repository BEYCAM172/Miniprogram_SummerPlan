# 暑期计划

微信原生小程序课程项目。用户可以设置暑假日期、创建目标和任务、安排重复计划、记录完成情况，并通过热力图回顾整个暑假。数据使用微信云开发同步，本地缓存支持离线查看与操作。

## 页面

- 今天：假期进度、周日期栏、任务时间轴、逾期任务和目标进度。
- 计划：月历、每日任务列表、任务编辑和目标管理。
- 我的暑假：完成统计、热力图、同步状态与数据管理。

## 云开发

部署前按照 [CLOUD_SETUP.md](./CLOUD_SETUP.md) 创建集合、权限、索引并上传两个云函数。小程序采用云开发静默身份识别，不获取昵称、头像和手机号。

## 互评演示建议

1. 首次进入选择“使用示例计划体验”。
2. 在今天页完成一项任务，展示进度即时更新。
3. 在计划页新增每周重复任务并关联目标。
4. 返回目标页查看进度，再到我的暑假展示热力图和云端同步状态。
